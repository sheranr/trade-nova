# Trade Nova

**Smarter Trade. Greater Confidence.** — HS codes, import control, levies and trade finance tools for Sri Lanka.
Created by Sheran Rajaguru.

- Web app: https://sheranr.github.io/trade-nova/
- Android download: https://sheranr.github.io/trade-nova/download/

## How it is built

| Folder | What it is |
|---|---|
| `src/app.html` | The app itself (one file: screens, logic, styles). Edit this. |
| `docs/` | The published site (GitHub Pages): web app, data (`hsdata.js`, `prices.js`), tariff PDFs, icons, service worker, OTA manifest, APK download page. Generated by `tools/release.py` — don't hand-edit `docs/index.html`, `docs/sw.js` or `docs/ota/version.json`. |
| `android/` | The Android app shell (apktool project). `android/assets-src/boot.html` is the bootloader that picks the newest verified app bundle. |
| `tools/` | `release.py` (publish an update), `build_apk.sh` (build and sign the APK), `sw.template.js`. |

## How updates reach users

1. **Android app (OTA content updates):** on start-up, when online, the app reads `docs/ota/version.json`, checks its ECDSA signature against the public key built into the app, downloads the changed files, checks each SHA-256 hash, and applies the update on the next start. Offline, it keeps using its last good version. A bad update is rolled back automatically.
2. **Android app (new APK):** when `version.json` lists a higher APK version, the app shows a *Download* banner that opens the download page.
3. **Web app / PWA:** the service worker caches the app for offline use and installs new versions in the background; users tap *Restart* to load them.

## Publishing an update

```sh
# 1. edit src/app.html (and/or docs/hsdata.js, docs/prices.js)
# 2. sign and publish
python3 tools/release.py --version 2.0.1 --notes "What changed" --key /safe/place/ota-signing-private.pem
# 3. commit and push — GitHub Pages serves it within a couple of minutes
```

For a new APK: bump `versionCode`/`versionName` in `android/apktool.yml` and `android/AndroidManifest.xml`, run `tools/build_apk.sh`, then `release.py` with `--apk file.apk --apk-code N --apk-version X.Y.Z`.

## Keys — never commit these

- `ota-signing-private.pem` — signs updates. Anyone with it could push updates to every installed app.
- `trademate-release.jks` + password — signs the APK. Without it, installed apps cannot be updated.

Keep both offline and backed up (e.g. a private drive), and turn on two-factor authentication for this GitHub account.

## Data

The HS tariff data (`docs/hsdata.js`, 9,007 lines from Sri Lanka Customs NITG 2026, checked against the PDFs on 16 Oct 2026) is a locked baseline: change it only for a new gazette or a confirmed correction, and record which lines changed.
Trade Nova is a reference tool — always confirm with the current Sri Lanka Customs tariff and with Customs before acting.
