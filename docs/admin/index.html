Sign in

Only the owner of the Trade Nova GitHub repository can change the app. Paste your GitHub access token to continue. It never goes into the app and is not sent anywhere except GitHub.

First time: create your token (once)

  1. On GitHub, open Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Name: Trade Nova admin. Expiration: up to 1 year.
  3. Repository access: Only select repositories → sheranr/trade-nova.
  4. Permissions → Repository permissions → Contents: Read and write. Nothing else.
  5. Generate, copy the token and paste it above. Keep it private, like a password.
